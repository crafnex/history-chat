# 偉人AIグループチャット (PWA Web App)

200人の歴史偉人・賢人・現代レジェンドと議論・相談ができるAIグループチャットWebアプリです。  
スマホ（Android / iPhone）にネイティブアプリとしてインストールして利用できます。

---

## 🚀 Webへの公開方法（デプロイ手順）

このフォルダ内のファイルを以下のいずれかにアップロードするだけで、即座にスマホで開ける `https://〜` のURLが発行されます。

### 方法A: Cloudflare Pages（一番おすすめ・無料）
1. [Cloudflare](https://dash.cloudflare.com/) にログインし、「Workers & Pages」➔「Pages」➔「ダイレクト アップロード」を選択。
2. このフォルダ全体（`index.html`、`character_details.js`、`manifest.json`、`sw.js`、`icons/`）をブラウザ画面にドラッグ＆ドロップ。
3. デプロイボタンを押すと、数十秒で `https://〇〇.pages.dev` のURLが発行されます。

### 方法B: GitHub Pages（無料）
1. GitHub にリポジトリを作成し、このフォルダ内のコードを push。
2. リポジトリの **Settings ➔ Pages** を開き、「Branch: master / (root)」を選択して保存。
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開されます。

## 📱 スマホでのインストール手順

発行されたURLをスマホのブラウザで開きます。

- **iPhone (Safari)**:
  - 画面下の共有ボタン <kbd>⎋ / [↑]</kbd> をタップし、**「ホーム画面に追加」** を選択。
- **Android (Chrome)**:
  - 右上の「📲 インストール」ボタン、またはブラウザメニュー（︙）から **「アプリをインストール」** をタップ。

### 初回利用フロー
インストール後、ホーム画面のアプリアイコンから起動すると、初回に「APIキー設定」が開きます。  
ご自身の **Groq（完全無料・超爆速）** または **Gemini** のキーを入力すれば、以降はずっと快適に利用できます。

## 🔄 今後のアプリのアップデート手順（新機能・新キャラ追加時）

HTMLやデータを更新してWeb上に再アップロードした際、スマホ側で確実に最新版へ更新させる手順です。

1. **[sw.js](sw.js) のバージョン番号を上げる**
   ```javascript
   const APP_VERSION = 'v1.0.1'; // ← 番号を1つ上げる（例: v1.0.0 ➔ v1.0.1）
   ```
2. **[index.html](index.html) のバージョン番号を合わせる**
   ```javascript
   const APP_CLIENT_VERSION = 'v1.0.1';
   ```
3. **Webへアップロード（再デプロイ）**
   - Cloudflare Pages または GitHub に更新ファイルをアップロード。
4. **スマホ側の挙動**:
   - ユーザーがアプリを開くと、自動的に画面上部に **「✨ 最新バージョンが届きました！ [今すぐ更新]」** バナーが表示されます。
   - または、設定画面内の **「🔄 最新版を確認」** ボタンを押すだけで、いつでも最新版へ瞬時に更新されます。
